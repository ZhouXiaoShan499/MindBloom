## 一、产品项目

### 1.1 项目概述

**MindBloom** 是一盏面向书桌学习的 **智能台灯**：基于 **24GHz 毫米波微动雷达** 与 **ESP32-S3 本地策略引擎** 的桌面学习辅助设备。它通过 **柔和的光线变化** 陪伴你专注与休息，在 **不增加「被监视感」** 的前提下，帮助你 **缓解** 学习过程中常见的紧张、拖延后的自责等 **心理消耗**。

> **合规声明**：本产品属于 **作息与放松辅助（Wellness）**，不用于诊断、治疗任何心理疾病或生理疾病；灯光与提示 **不构成医学建议**，不能替代心理咨询或医疗服务。

### 1.2 一句话定位

一盏默认 **无 App、无摄像头、无麦克风、不上传个人学习行为数据** 的桌面台灯；通过 **24GHz 毫米波微动雷达** 感知你是否在桌前及身体活动强弱，用 **极缓慢的光变化** 做久坐提示，并提供 **手动放松光效**；以 **可一键恢复** 的方式，让你在备考与自习时更安心。

### 1.3 产品亮点

| 亮点 | 说明 |
|------|------|
| 🔒 **隐私友好** | 无影像、无拾音；默认本地处理，不上传云端 |
| 🤫 **低打扰** | 无声、无弹窗；光变化 **幅度克制、速度慢** |
| 🔄 **信任设计** | **一键重置** 覆盖智能推断，用户对状态拥有最终解释权 |
| 🎯 **场景聚焦** | 宿舍 / 租房书桌 / 图书馆自习位等久坐学习场景 |
| 💰 **成本可控** | 光学与交互做减法（白光优先、旋钮优先），落在学生可负担区间 |

### 1.4 核心解决方案链路

```
感知层（雷达检测）→ 推理层（本地策略引擎）→ 反馈层（光语反馈）
```

- **感知层**：雷达提供 **在位 / 离开**、**活动强弱代理特征**（能量、距离门限内统计等）
- **推理层**：以 **状态机 + 可调阈值** 为主，可选轻量端侧模型
- **反馈层**：**暖白光常态** → **极缓慢变暗（久坐提示）** → **手动呼吸光**；**一键重置** 优先级最高

## 二、面向的用户

### 2.1 核心用户画像

| 维度 | 描述 |
|------|------|
| **年龄** | 16～30 岁 |
| **身份** | 中学生、大学生、考研/考公/考证等备考群体、远程学习者 |
| **居住环境** | 宿舍、合租房、单人公寓、家庭书房 |

### 2.2 用户行为特征

- 每日有 **2～8 小时** 连续桌面学习需求
- 习惯在 **安静环境** 中学习，对噪声与强光干扰敏感
- 对 **电子设备隐私** 有一定认知与警惕
- 尝试过番茄钟、Forest 等效率工具，但感觉 **「被监视」或「提醒生硬」**

### 2.3 用户心理特征

- 容易陷入 **拖延—自责循环**
- 备考压力大时会出现 **心慌、呼吸变浅** 等生理紧张反应
- 渴望一种 **私密、低打扰** 的方式来帮助自己 **慢下来**，但不想用手机（易分心）

### 2.4 不适用的用户

- 需要医疗诊断或治疗的情绪与躯体问题，请咨询专业机构
- 希望设备具备「监督学习」「识别是否在玩手机」等监控功能的用户
- 对雷达电磁波敏感或存在安装限制的用户

## 四、解决的核心痛点是什么

### 痛点 1：拖延—自责循环 🔄

> **问题**：开始前犹豫、开始后走神，往往在不知不觉消耗大量时间后产生强烈自责。

**MindBloom 的解法**：
- **极缓慢变暗** 的光提示，温和地将你的注意力拉回当下
- 不评判、不说教、不弹窗，避免「被指责」的心理压力
- 活动回升后 **平滑恢复** 亮度，正面强化「回到状态」的行为

### 痛点 2：紧张难以平复 💓

> **问题**：备考中出现心慌、呼吸变浅等感受时，缺少 **私密、低打扰** 的平复方式，容易转向刷手机并加重负罪感。

**MindBloom 的解法**：
- **手动呼吸光**：长按约 2 秒进入，以约 10～12 秒周期缓慢明暗起伏
- **幅度克制**（±3%～±10%），不影响室友，余光即可感知
- **一键退出**，随时可以终止，控制权始终在你手中

### 痛点 3：反馈生硬 🔔

> **问题**：部分工具只强调时长统计或强提醒，缺少「体面、低监视感」的提示方式。

**MindBloom 的解法**：
- **无声、无弹窗**：用光做提示与陪伴
- **极慢变化**：所有亮度变化设最大斜率，避免跳变与眩光
- **有下限**：亮度下降有下限（如 ≥60%～70%），不会突然全黑

### 痛点 4：隐私敏感 🔒

> **问题**：排斥摄像头、麦克风与不明云端上传，希望设备默认 **本地、可控**。

**MindBloom 的解法**：
- **无摄像头、无麦克风**（若未来增加语音功能，视为另一条产品线）
- **默认不上传** 行为数据至云端
- **无账号体系**，不出厂绑定云平台
- 数据默认留存设备内，用户完全掌控

## 五、技术栈

### 5.1 硬件方案

| 模块 | 型号/方案 | 说明 |
|------|-----------|------|
| 🧠 **主控** | ESP32-S3-WROOM-1 | 双核 Xtensa LX7 处理器，支持 TFLite Micro（可选） |
| 📡 **雷达** | HLK-LD2420B（24GHz） | UART 接口，输出在位/离开、距离门限内目标、能量/微动等级 |
| 💡 **主照明** | COB 冷白 + COB 暖黄双通道 | 双通道独立 PWM 调光，支持冷白～暖黄无级调色温 |
| 🌈 **氛围光（可选）** | WS2812 RGB LED（3～6 颗） | 与白光通道解耦，仅作点缀 |
| 🔘 **交互** | 机械旋钮 + 按键（推荐） | 低成本、低误触、易解释「重置」 |
| ⚡ **电源** | 5V / 2A USB-C | 按峰值电流留裕量 |
| 🔧 **结构** | PCB 集成（自制 PCB） | DevKit 原型 → 量产自制 PCB |

```

### 5.3 状态机设计（内部）

| 内部状态 | 说明 | 用户感知 |
|----------|------|----------|
| `IDLE_OFF` | 无人 → 灯灭/待机 | 灯灭 |
| `BASE_STUDY` | 在位且未触发久坐提示 | 稳定暖白光（亮度可调） |
| `LOW_ACTIVITY_NUDGE` | 长时间低活动累计超过阈值 | 暖光极缓慢变暗（有下限） |
| `BREATHE_MANUAL` | 手动进入呼吸放松模式 | 柔和起伏呼吸光 |
| `LEAVE_DIM` | 离开后延时缓灭 | 先降亮待机，再完全熄灭 |

**优先级（从高到低）**：用户重置 / 手动退出呼吸 → 离开熄灯逻辑 → 呼吸模式内规则 → 久坐缓暗累计

### 5.4 功能分阶段 Roadmap

| 阶段 | 范围 |
|------|------|
| **MVP** | 在位亮灭、久坐缓暗、活动恢复、手动呼吸、一键重置、灵敏度档位、白光优先 |
| **V1.1** | 触控环调光调色、画圈念头标记（若误触率达标）、可选自动安抚（默认关闭） |
| **V2** | 结束仪式光轨、7 日摘要回顾、TFLite 低活动分类、第二传感器融合 |

### 5.5 MVP 参数示例（需实测标定）

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 久坐提示启动窗口 | 25～35 分钟低活动 | 可配置 |
| 变暗速率 | 每 15 分钟 −3% | 有速率上限 |
| 亮度下限 | ≥60%～70% | 可配置 |
| 呼吸光周期 | 10～12 秒 | 正弦或分段线性 |
| 呼吸光幅度 | ±3%～±10% | 以主观舒适 + 无可见频闪为准 |

## 六、软件示意

### 6.1 光语模式对照表

| 模式名称 | 用户感知 | 典型触发场景 |
|----------|----------|-------------|
| 📖 **常态学习光** | 稳定、舒适的暖白阅读光（亮度可调） | 你在桌前正常使用台灯 |
| ⏰ **久坐提示光** | 光线 **极缓慢** 变暗一点，提醒你动动身体或把注意力拉回眼前事 | 长时间几乎没明显活动时（思考时也可能很静，若不合适请按重置） |
| 🌬️ **放松呼吸光** | 亮度 **缓慢起伏**，像呼吸节奏，帮助你主观上放慢一点 | **默认由你长按开启**；结束时再按一下或按重置即可 |
| 🌙 **离开缓灭** | 离开一段时间后先变暗待机，再完全熄灭 | 离开书桌超过设定时间 |

> **说明**：产品对外不使用「专注光」「焦虑光」等心理学诊断用语；灯光只做 **陪伴与提示**。

### 6.2 交互逻辑流程

```

         │
         ▼
    常态学习光（稳定暖白光）
         │
    ┌────┴────┐
    │         │
    ▼         ▼

    │         │
    ▼         ▼

    │         │

    │         │
    └────┬────┘

```

### 6.3 MVP 功能清单（对外承诺）

| 功能 | 说明 |
|------|------|
| ✅ **人来亮 / 人走缓灭** | 坐到桌前灯渐亮；离开一段时间后先变暗待机，再完全熄灭，避免刺眼跳变 |
| ✅ **阅读照明** | 支持无级调亮度；色温调节若提供，以产品规格页实测为准 |
| ✅ **一键重置** | 任何时候觉得灯光不合适，**单击** 即可恢复到你设定的正常灯光，并清除当前久坐提示累计 |
| ✅ **久坐提示** | 长时间低活动时，灯光 **很慢** 变暗，有亮度下限，不突然打断 |
| ✅ **活动恢复** | 当你有明显活动（如起身、整理物品）时，灯光在数秒内 **平滑恢复** |
| ✅ **手动放松呼吸光** | **长按约 2 秒** 进入；**短按或重置** 退出（以说明书为准） |
| ✅ **灵敏度档位（若有）** | 可选低 / 中 / 高或关闭久坐提示，适配宿舍与图书馆等不同环境 |

### 6.4 首发版本不对外承诺

- 自动识别「焦虑」、读取「心率」、区分「刷题手机与娱乐手机」
- 语音记录、云端账号与数据同步
- 复杂手势（如画圈）及多日「情绪光轨」回顾
- 部分能力可能作为 **后续升级** 单独说明

          │  [按键]  │      ← 重置 / 呼吸光按键
          │  USB-C   │      ← 供电接口
          └─────────┘
      MindBloom
```
