## 一、产品项目

### 1.1 项目概述

**MindBloom** 是一盏面向书桌学习的 **AI 环境智能灯**：基于 **24GHz 毫米波微动雷达** 与 **ESP32-S3 本地策略引擎**，它通过 **柔和的光线变化** 无声地配合你的学习节奏。与市面上的台灯不同，MindBloom 会 **慢慢学会你的个人习惯**——你不需要告诉它你要专注多久，它自己会观察、适应，并在你真正需要的时候给出恰到好处的提醒。

> **合规声明**：本产品属于 **作息与放松辅助（Wellness）**，不用于诊断、治疗任何心理疾病或生理疾病；灯光与提示 **不构成医学建议**，不能替代心理咨询或医疗服务。

### 1.2 一句话定位

一盏默认 **无 App、无摄像头、无麦克风、不上传任何数据** 的桌面灯；通过 **24GHz 毫米波微动雷达** 感知你是否在桌前及身体活动强弱，用 **本地 AI 学习你的专注模式**，以 **极缓慢的光变化** 做无声提醒；所有学习数据仅存本地，隐私始终在你手中。

### 1.3 产品亮点

| 亮点 | 说明 |
|------|------|
| 🤫 **静默配合** | 无声、无弹窗；光线变化幅度克制、速度缓慢，不打断你的思考 |
| 🤖 **AI 自适应** | 灯会慢慢学会你的"安静"是什么程度、你通常专注多久—越用越懂你 |
| 🔒 **隐私友好** | 无影像、无拾音；所有学习数据默认本地处理，不上传云端 |
| 🔄 **信任设计** | 一键重置覆盖智能推断，用户对状态拥有最终解释权 |
| 🎯 **场景聚焦** | 宿舍 / 租房书桌 / 图书馆自习位等久坐学习场景 |
| 💰 **成本可控** | 光学与交互做减法（白光优先、旋钮优先），落在学生可负担区间 |

### 1.4 核心链路

```
感知层（雷达检测）→ 学习层（本地AI画像）→ 推理层（策略引擎）→ 反馈层（光语反馈）
```

与传统智能台灯的区别：**中间多了一层"学习"**。不是预设规则，而是灯在观察你、适应你、最终配合你。

## 二、面向的用户

### 2.1 核心用户画像

| 维度 | 描述 |
|------|------|
| **年龄** | 16～35 岁 |
| **身份** | 中学生、大学生、考研/考公/考证等备考群体、远程学习者、自由职业者 |
| **居住环境** | 宿舍、合租房、单人公寓、家庭书房 |

### 2.2 用户行为特征

- 每日有 **2～8 小时** 连续桌面学习/工作需要
- 习惯在 **安静环境** 中工作，对噪声与强光干扰敏感
- 对 **电子设备隐私** 有一定认知与警惕
- 尝试过番茄钟、Forest 等效率工具，但感觉 **「提醒太生硬」「容易分心去看手机」**

### 2.3 用户心理特征

- 希望有一盏灯能**安静地陪伴**，而不是"管"自己
- 想要一种**不需要操作手机**的方式来感知时间流逝
- 渴望书桌环境能**随自己的状态自然变化**

### 2.4 不适用的用户

- 需要医疗诊断或治疗的情绪与躯体问题，请咨询专业机构
- 希望设备具备「监督学习」「识别是否在玩手机」等监控功能的用户
- 对雷达电磁波敏感或存在安装限制的用户

## 三、解决的问题

### 痛点 1：固定规则太死板

> **问题**：传统番茄钟固定 25 分钟，但每个人的专注节奏不同——有的人能持续专注 90 分钟，有的人 15 分钟就会自然走神。固定规则对所有人都是一种"打扰"。

**MindBloom 的解法**：
- 灯会观察你的活动模式，**慢慢学会你的个人专注时长**
- 如果你的典型专注是 45 分钟，它就在 45 分钟后才提示——不是 25 分钟
- 如果你深度沉浸时几乎不动，它不会因为"静止太久"就打断你

### 痛点 2：反馈生硬 🔔

> **问题**：大部分工具的提醒方式是弹窗、铃声、震动—这些在安静的学习环境中都很突兀。

**MindBloom 的解法**：
- **只用光**：极缓慢的亮度变化是唯一的提醒方式
- **无声、无弹窗**：不会让你在图书馆里尴尬
- **幅度克制**：有亮度下限（≥60%），不会突然变黑

### 痛点 3：注意力分散后的回归

> **问题**：走神后重新集中注意力需要时间，缺少一种"无感"的方式帮自己回到状态。

**MindBloom 的解法**：
- 当你活动回升（回到书桌、整理东西后再次开始学习），灯光平滑恢复亮度
- 这是一个**正面反馈**：灯用光告诉你"你回来了，继续吧"
- 手动呼吸光：想让自己慢下来时，长按进入，灯会以呼吸节奏缓慢明暗起伏

### 痛点 4：隐私敏感 🔒

> **问题**：排斥摄像头、麦克风与不明云端上传，希望设备默认本地、可控。

**MindBloom 的解法**：
- **无摄像头、无麦克风**
- **默认不上传** 行为数据至云端
- **无账号体系**，不出厂绑定云平台
- 所有 AI 学习数据默认保留设备内，用户完全掌控

## 四、核心能力

### 4.1 基础能力

| 能力 | 说明 |
|------|------|
| ✅ **人来亮 / 人走缓灭** | 坐到桌前灯渐亮；离开一段时间后先变暗待机，再完全熄灭 |
| ✅ **阅读照明** | 支持无级调亮度；色温调节若提供，以产品规格页实测为准 |
| ✅ **一键重置** | 任何时候觉得灯光不合适，单击即可恢复，并清零当前累计 |
| ✅ **久坐提示** | 长时间持续低活动时，灯光很慢地变暗（有亮度下限） |
| ✅ **活动恢复** | 当你活动回升（如起身、整理物品），灯光在数秒内平滑恢复 |
| ✅ **手动呼吸光** | 长按约 2 秒进入柔和起伏光；短按或重置退出 |
| ✅ **灵敏度档位** | 可选快/中/关闭久坐提示，适配不同学习环境 |

### 4.2 AI 自适应能力（V2 新增）

| 能力 | 说明 |
|------|------|
| 🤖 **自适应安静基线** | 灯会学习你个人的"安静"是什么水平，而不是用统一标准判断 |
| 🤖 **专注时长学习** | 记录你每次专注的时长，动态调整久坐提示窗口，避免在不合适的时候打断你 |
| 🤖 **本地画像** | 所有学习数据仅存本地 JSON，不上云、不联网、不绑定账号 |

## 五、技术栈

### 5.1 硬件方案

| 模块 | 型号/方案 | 说明 |
|------|-----------|------|
| 🧠 **主控** | ESP32-S3-WROOM-1 | 双核 Xtensa LX7 处理器，支持 TFLite Micro |
| 📡 **雷达** | HLK-LD2420B（24GHz） | UART 接口，输出在位/离开、距离门限内目标、能量/微动等级 |
| 💡 **主照明** | COB 冷白 + COB 暖黄双通道 | 双通道独立 PWM 调光，支持冷白～暖黄无级调色温 |
| 🌈 **氛围光（可选）** | WS2812 RGB LED（3～6 颗） | 与白光通道解耦，仅作点缀 |
| 🔘 **交互** | 机械旋钮 + 按键（推荐） | 低成本、低误触、易解释「重置」 |
| ⚡ **电源** | 5V / 2A USB-C | 按峰值电流留裕量 |
| 🔧 **结构** | PCB 集成（自制 PCB） | DevKit 原型 → 量产自制 PCB |

### 5.3 状态机设计

| 内部状态 | 说明 | 用户感知 |
|----------|------|----------|
| `IDLE_OFF` | 无人 → 灯灭/待机 | 灯灭 |
| `BASE_STUDY` | 在位且未触发久坐提示 | 稳定暖白光（亮度可调） |
| `LOW_ACTIVITY_NUDGE` | 长时间低活动（基于自适应阈值）累计超过学习窗口 | 暖光极缓慢变暗（有下限） |
| `BREATHE_MANUAL` | 手动进入呼吸放松模式 | 柔和起伏呼吸光 |
| `LEAVE_DIM` | 离开后延时缓灭 | 先降亮待机，再完全熄灭 |

**优先级（从高到低）**：用户重置 / 手动退出呼吸 → 离开熄灯逻辑 → 呼吸模式内规则 → 久坐缓暗累计

### 5.4 功能分阶段 Roadmap

| 阶段 | 范围 |
|------|------|
| **MVP** | 在位亮灭、久坐缓暗、活动恢复、手动呼吸、重置、灵敏度档位、白光优先 |
| **V2（当前）** | **AI 自适应基线 + 专注时长学习 + 本地画像持久化** |
| **V2.1** | 触控环调光调色、画圈念头标记（若误触率达标）、可选自动安抚（默认关闭） |
| **V3** | TFLite Micro 时序分类（专注/思考/分心/疲劳）、结束仪式光轨、7 日摘要回顾 |

### 5.5 MVP 参数示例（需实测标定）

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 久坐提示启动窗口 | 动态（初始 25min，AI 调整至 10~60min） | AI 根据用户历史专注时长自动调整 |
| 变暗速率 | 每 15 分钟 −3% | 有速率上限 |
| 亮度下限 | ≥60%～70% | 可配置 |
| 呼吸光周期 | 10～12 秒 | 正弦或分段线性 |
| 呼吸光幅度 | ±3%～±10% | 以主观舒适 + 无可见频闪为准 |
| 安静基线 | 动态 0.05~0.50 | AI 根据用户实际运动数据实时调整 |

## 八、AI 学习机制

MindBloom V2 引入了基于统计学习的用户行为画像系统。所有 AI 能力均在设备本地运行，不需要联网。

### 8.1 自适应安静基线

每个人的"安静"程度不同——有人看书时完全不动（motion_level ≈ 0.05），有人会无意识地抖腿、转笔（motion_level ≈ 0.25）。

- 旧版本：写死 `motion_level < 0.3` 算低活动 → 抖腿的人永不会被提醒，看书的人 15 分钟就被提示
- **V2 版本**：灯会在你安静学习时默默观察你的 motion_level，计算出 **你个人** 的安静基线

### 8.2 专注时长学习

每个人的专注节奏不同：

- 有人习惯 25 分钟起身上厕所一次
- 有人一旦进入心流可以连续 90 分钟不动

MindBloom 会记录你每次专注的持续时间，取中位数作为你的"典型专注时长"，并以此调整久坐提示窗口——**不会在你正常专注周期内打断你**。

### 8.3 本地画像持久化

学习到的用户画像会被保存为本地 JSON 文件。每次开机时自动加载，从而保证：
- 灯是**越用越懂你**的，而不是每次重新开始
- 所有数据**仅存本地**，不上云、不联网、不绑定账号
- 用户完全掌控自己的数据

### 8.4 未来：TFLite Micro 时序分类（V3）

在 Phase 2 中，我们将训练一个轻量级 TFLite 模型（<30KB），输入为 30 秒滑动窗口的 `motion_level` 序列，输出为：

```
专注 / 思考中 / 分心 / 疲劳
```

而不是当前简单的"低活动/高活动"二分类。这能让灯更精准地理解你的状态，做出更自然的配合。
